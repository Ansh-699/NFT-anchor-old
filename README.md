# NFT Anchor Old

This project contains an Anchor smart contract implementation for NFTs on Solana.

## Project Structure

```
NFT-anchor-old/
├── migrations/
├── programs/
├── tests/
├── Anchor.toml
├── Cargo.toml
├── package.json
└── tsconfig.json
```

## Getting Started

Follow these instructions to run the project locally.

### Prerequisites

- Rust
- Solana CLI
- Anchor CLI
- Node.js and Yarn

### Installation

1. Install project dependencies:

   ```bash
   yarn install
   ```

### Usage

1. Build the program:

   ```bash
   anchor build
   ```

2. Run tests:

   ```bash
   anchor test
   ```
